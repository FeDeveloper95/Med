# Med

**Never miss your medicine ever again.**

![Badges](/images/badges.svg)

### :sparkles: Features

Med helps you keep track of your medicines and medical history with ease. You can log quick actions for immediate entry or create detailed custom events when needed. Notifications aren't enough? Med can also set alarms to remind you when it's time to take your medication. Scheduling is highly flexible, allowing you to set recurrences daily, on specific days of the week, or with a fully custom interval. The setup process is intuitive and fast.
Additionally, Med includes an integrated in-app update system to ensure you are always running the latest version.

### :art: Design

The UI is built strictly following the latest **Material 3 Expressive** guidelines using Jetpack Compose to keep the app clean, fluid, and modern. Designed with **Pixel** aesthetics as a priority, it functions seamlessly on any Android 8+ device, adapting perfectly across standard phones, foldables, tablets, and desktops.
